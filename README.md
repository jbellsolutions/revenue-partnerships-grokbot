# Revenue Partnerships 3.0: GrokBot pack

A team of Grok agents that runs all nine Revenue OS functions: one lead agent, and one agent per function ([TEAM.md](TEAM.md)). You paste one line into the lead; it sets up the other nine. The core email (Dream 100, Dream 500, cold leads) is Justin looking for a fractional staff role; Lead Radar reads the AI Guy Lead Radar and the job sites for it. Partners, SpeakerAgent, content, and AEO and SEO run on the partnerships message, "never buy leads again". Which function says what: [OFFER.md](OFFER.md).

**One link.** Tell a Grok bot to download `https://github.com/jbellsolutions/revenue-partnerships-grokbot/releases/latest/download/revenue-partnerships.zip` and follow [HANDOFF.md](HANDOFF.md). The exact line to paste is in HANDOFF.md, Part 1, step 4.

## One pack, two tiers

All nine Revenue OS functions are in the pack. A tier decides which are switched on: `python3 tools/tier.py revenue-partnerships` lists 31 routines, `python3 tools/tier.py revenue-os` all 41. This install runs all nine by default, as ten agents (`python3 tools/team.py list`); the Revenue Partnerships 3.0 tier is seven. The same pack is what a customer's own bot is installed from, with the customer's business in `campaign.json` and the tier they bought.

## What it is built from

The Revenue OS template (the nine functions in [agents/](agents/README.md), the engine router, the conversation log, the LinkedIn path) on the base kit's roles, skills, guard scripts and worker. Nothing here has run on a Grok bot yet: every routine is created paused and starts on test.
