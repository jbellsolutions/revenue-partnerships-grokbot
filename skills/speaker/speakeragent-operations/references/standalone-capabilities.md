# Capability map: with or without SpeakerAgent.ai

The independent mode reproduces the user's working process and outputs. It does not claim an identical hosted UI, proprietary database, vendor credits, hidden contact service or numerical model judgment.

| SpeakerAgent function | Independent Hermes equivalent | Optional account/service benefit |
|---|---|---|
| Speaker persona and talk topics | Local persona.json, supplied bio/site, conversation and constraints | Import existing persona through scoped CLI/dashboard |
| Conference matching | Persona-derived queries; official calendars/directories; browser review; original Alpha relevance distinctions | Dashboard discoveries and existing saved cases |
| Seminars/workshops/webinars/panels | Extended event vocabulary, organizer and social recruitment signals; same qualification gates | No platform dependency |
| Podcast discovery | Public show sites, RSS, directories and available APIs; real guest-format review | Existing platform catalog/provider access |
| Scoring | Bundled source-aligned arithmetic; model judgment plus evidence for inputs | Compare imported platform scores; do not trust them blindly |
| Paid-speaking qualification | Explicit speaker compensation and session-specific terms, currency and minimum-fee check | Imported flags remain claims to verify |
| Contact research | Official speaker/program/team pages, forms, public professional profiles, evidence per candidate | Authorized enrichment can fill gaps |
| Email verification | Published ownership and route purpose; distinguish unknown deliverability | A real mailbox-verification provider is needed for deliverability claims; DNS alone is insufficient |
| Human connection | Supplied speaker facts plus checked host/organizer details | Existing HC records may be imported and rechecked |
| Voice and personalization | Client writing samples, extracted style, truthful topic/hook and audience value | Optional platform voice profile |
| Pitch writing and review | Local drafts, authenticity check and revisions | Existing dashboard drafts/pipeline |
| Pipeline and progress | Saved cases, history, source files, day reports and stable identities | Hosted UI and shared team views |
| Daily proactive work | Hermes CLI + bounded wrapper + native cron + supervised gateway | SaaS account does not create this runtime |
| Social discovery | Public web/browser; authorized account connectors when available | Optional One API/Treg/social provider; no paid tool presumed |
| Sending/submitting | Only through an available client-authorized channel after actual instruction | Neither the bundled podcast CLI nor this research package sends automatically |

If the client declines SpeakerAgent.ai, do not say that conference research, scoring, drafting or pipeline work is unavailable. Those outputs have local implementations/instructions. Be candid about unavoidable limits: no public source may identify a speaker fee, a private social post may be inaccessible, a mailbox may remain unverified, and model/hosting usage still needs working credentials or included credits. “No SpeakerAgent account” does not mean “no computer, no model, no network or free unlimited paid data.”
