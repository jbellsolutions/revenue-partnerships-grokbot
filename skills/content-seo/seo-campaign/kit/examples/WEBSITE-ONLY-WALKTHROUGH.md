# Illustrative walkthrough — no real campaign was run

Input: `https://example.com`, no grant or credentials. This reserved example address is a placeholder. All outcomes below describe required behavior, not observed results.

The director creates local state and the seed project. It reads the actual supplied site's pages and derives a provisional business model, core offer, customer tasks and conversion path. It commissions a research analyst and technical specialist only if delegation is permitted; otherwise it completes those preparation steps itself and records the runtime gap.

Suppose evidence establishes a real local service business with a useful core service page and a broken contact link. The director creates tasks to fix the link, improve the current service page and investigate a cost guide. It records prices, real coverage and case evidence as unknown where absent. It does not invent pages for every surrounding city.

The information architect maps the service hub, relevant detail and cost guide on the current domain. A proposed calculator on a subdomain gets an explicit useful-purpose and hosting assessment. With no DNS scope it stays a complete candidate plan. The production team writes and builds a preview from supported facts, and the independent verifier checks the exact candidate if separate review is available.

Without publishing scope the output is a reviewable release package, not a live release. Without a real scheduler the runtime report says no automatic continuation exists. The board still shows useful completed draft tasks and accurately blocked publication/activation tasks.

Later, the owner supplies scoped CMS/host/DNS access, an operating window, finite cost caps and explicit delegation, publishing and recurrence authority. The director reuses the existing project; normalizes that grant; reconciles prior actions; releases the checked candidate; verifies live behavior; and configures one dispatcher. It proves a future scheduled run, exclusive ownership, cancellation and caps before calling the campaign unattended-ready.

At the evaluation date the analyst reports actual comparable outcomes or insufficient data. The director chooses the next improvement from the diagnosed bottleneck. Neither page creation nor bot creation establishes commercial success.
