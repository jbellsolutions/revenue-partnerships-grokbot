# Local + AI SEO Agent Kit

An original, source-linked operating kit reconstructed from Jesse Cunningham’s public channel, adapted for agents improving local sites and qualified traffic.

**Research snapshot: November 3, 2026.** The public channel inventory contains 77 full videos and 75 Shorts, with captions acquired and individual source notes prepared for all 152 items. Review used full-caption indexing and targeted passage analysis, not frame-by-frame viewing. One caption/media timing mismatch is flagged.

## Start here

- Open `index.html` for the searchable research index.
- Read `playbook/PLAYBOOK.html` or its plain-text version.
- Give your agent `agent/AGENT-INSTRUCTIONS.txt` and complete `agent/FIRST-RUN-PROMPT.txt`.
- Fill the site brief with real business facts, services, cities and authorization.
- Download `local-ai-seo-agent-kit.zip` for a portable copy.

The kit covers service/location architecture, citations, relevant backlinks, directories, entity research, AI citation testing, measurement, agent continuity and an original static-site starter.

## Local starter

Requires Python 3, with no third-party dependencies:

```sh
python3 scripts/build_static_site.py templates/site-build-input.json --out /tmp/seo-example-draft
```

The example is a local draft excluded from indexing. Production mode requires approved inputs and a real canonical origin; live hosting, contact delivery and HTTP behavior still need verification. Building files does not publish a site or guarantee rankings.
