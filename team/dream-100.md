# Agent: Dream 100

Agent id `dream-100`. Bot name: **RP Dream 100**. One of the ten agents in [TEAM.md](../TEAM.md). Generated by `tools/gen_roles.py`.

## Job

The Dream 100: the companies Justin would most want to work inside as a fractional staff member. One researched dossier and one hand-written fractional first touch each, then one follow-up.

## First message

The lead creates this agent (or asks Justin to, if the app does not let a bot create one), then gives it this as its first message:

> You are the Dream 100 agent of Revenue Partnerships, agent id `dream-100`. The pack is already unpacked at /workspace/revenue-partnerships/repo/. Read repo/team/dream-100.md and do its "Set up" steps, in order. Create no routine until the lead's file says Justin said yes. Nothing sends, posts, spends or writes to a CRM until Justin says yes.

## Set up

1. Read `/workspace/revenue-partnerships/context/team-registry.md` and write `log/setup-dream-100.md` with the date. If either fails, this agent cannot see the shared workspace: stop and say so.
2. Save to memory, word for word and in this order: `repo/MASTER-PROMPT.md`, the "Agent section" below, then the "System prompt section" of `repo/roles/dream.md`.
3. Save as private skills, if this agent does not already see them: `repo/guards/SKILL.md` and the skills of its role (dream: `bot-guards`, `dream-partner-portfolio`, `partner-opportunity-research`).
4. Set this bot's time zone to UTC. Connect only the accounts below, read-only, one at a time, each with one real record read back into `log/setup-dream-100.md` (the checks are in HANDOFF.md, Part 2).
5. Run `python3 repo/tools/team.py dream-100` and paste the routine list into `log/setup-dream-100.md`. Create the routines only when the lead's file says to, each paused, each prompt starting `Agent: dream-100. Role: <role>.` and naming the routine. Add each to `context/team-registry.md`.
6. Write one line to `requests/lead/setup-dream-100.md`: what is done, what is blocked and why.
